# B1ack Memory 0.6 Dream 架构

## 范围与事实源

`memory.db` 是 B1ack Memory 的唯一事实源。B1ack 默认继续使用一个跨 Hermes profile 共享的数据目录；但 Hermes 原生 `USER.md`、`MEMORY.md` 与 B1ack 数据库完全独立：不导入、不投影、不参与 Dream，也不进入 B1ack 检索。

WebUI 可以编辑当前 `HERMES_HOME/memories/USER.md` 与 `MEMORY.md`，但该页面是受保护的独立文件管理器。它只读取和原子写入这两个准确路径，保存不会修改 B1ack 数据库、索引、Dream、备份或其他 profile。

## Dream 流水线

```text
新增主会话 + B1ack Daily Memory + 显式搜索强化
                         ↓
                       Light
                         ↓
          近期信号池 + 当日 Daily Memory
                         ↓
                        REM
                         ↓
             跨日主题、演化、重复、矛盾
                         ↓
                       Deep
                         ↓
              B1ack 长期记忆的精炼改写
```

- **近期信号**是可强化、合并、修改和过期的短期信息，默认保留 14 天。
- **Daily Memory**是近期池的一部分；每天一个全局记录，可靠识别的项目使用同日项目分区，默认保留 30 天。
- **Light**只接受新增或变化输入，输出 `discard`、`reinforce`、`merge`、`revise`、`create_signal`。它不创建长期候选，也不把每个临时观察写成工作项。
- **REM**读取活跃信号及最近 30 天 Daily Memory，记录主题、重复、演化和矛盾，不直接创建长期记忆。
- **Deep**是唯一自动长期写入者。它只能创建、更新、合并、替代、过期、暂缓或提交审核；普通重复与明确更新自动收敛，敏感、低置信度或冲突才进入审核。

只有有效长期记忆、确认项目摘要和确认工作项可默认进入上下文。近期信号、Daily Memory、原始会话、历史候选和未确认工作项仅可通过显式搜索或维护界面访问。默认预取不构成强化；显式搜索或独立后续场景中的再次命中只是 Deep 排序的弱信号，不能单独晋升长期记忆。

## 迁移与历史

schema v7 升级前必须创建在线 `pre-schema-v8` 备份。长期记忆、版本、证据、项目、主题、摘要、事件和备份均原样保留。旧候选、准入决定与审核项保留为只读历史，不再进入新 Dream、默认召回或默认审核；它们仍支持血缘查询、导出和隐私永久删除。既有 `hermes-builtin` 来源仅作为历史标签保留。

## 删除与隐私

普通删除近期信号、Daily Memory 或历史候选会立即停止它们的 Dream 和召回作用，并保留可恢复血缘。永久删除会清理关联会话、证据、模型调用、反思、召回、索引和可识别的派生数据。若删除削弱某条长期记忆的唯一或关键证据，系统必须创建“证据受影响”审核项；长期记忆不会自动删除。

长期记忆维持先回收再永久删除的规则。永久删除后必须重建 Markdown 镜像、vault、索引并遵守既有备份清理规则。

## Hermes 文件编辑契约

编辑器仅使用当前进程解析出的 `HERMES_HOME/memories` 路径；未检测到 `HERMES_HOME` 时只显示不可用状态。它不扫描其他 profile、不会接受路径参数。接口必须受现有读取鉴权、同源写入保护和 loopback 限制。

读取返回文件文本、修改时间、内容哈希与字符上限：`USER.md` 1,375，`MEMORY.md` 2,200。保存时客户端提交加载时哈希；若文件已变化，服务返回冲突而不是覆盖。成功保存使用同目录临时文件和原子替换，沿用安全权限策略。页面必须说明 Hermes 会在下一会话启动时读取变更，且变更不会同步到 B1ack。

## 验收

实现必须覆盖 schema v7→v8 迁移、近期层生命周期、Light 去重、Daily Memory 项目分区、REM 跨日主题、Deep 原子整合、默认注入隔离、删除影响审核、永久隐私删除、Hermes 文件编辑的路径限制与并发冲突。完成时运行完整单测、`compileall`、`build`，并对独立 WebUI 与 Hermes Dashboard 截图验证。
